API belgeleri

Tüm uç noktalar JSON döndürür. İstek gövdeleri en fazla 16 KB, istemci hızı dakikada 120 API isteğiyle sınırlıdır.

/api/health

GET

/api/nearest

POST

/api/similarity

first ve second alanlarındaki iki sözcüğün benzerliğini ölçer.

POST

/api/analogy

POST

/api/sentence-similarity
